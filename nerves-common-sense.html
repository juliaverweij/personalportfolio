    Nerves & Common Sense

    Nerves & Common Sense is a book using found journal entries with a main focus on typographic elements. The content is a collection of journal entries of the The Ladies’ Home Journal written by Annie Payson Call together with illustrations from www.oldbookillustrations.com to help add a visual breather into the heavy text based book.
    Paper: Munken Cream 115gr (uncoated)
    Typeface: JetBrains Mono
    Binding: Ribbon (multi-functional use as binding and as a bookmark)
